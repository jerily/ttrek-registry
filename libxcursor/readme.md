# libxcursor

X11 cursor management library.

[Upstream](https://gitlab.freedesktop.org/xorg/lib/libxcursor) · 1.2.3 · HPND-sell-variant

```sh
ttrek install libxcursor
ttrek run -package libxcursor -script demo
```

Requires a C compiler and make.

Requires system X11 development headers and pkg-config (XQuartz on macOS). The example prints the installed pkg-config version.
