# libxfixes

X11 Fixes extension client library.

[Upstream](https://gitlab.freedesktop.org/xorg/lib/libxfixes) · 6.0.2 · HPND-sell-variant AND MIT

```sh
ttrek install libxfixes
ttrek run -package libxfixes -script demo
```

Requires a C compiler and make.

Requires system X11 development headers and pkg-config (XQuartz on macOS). The example prints the installed pkg-config version.
