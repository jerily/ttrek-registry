# ncurses

Terminal capabilities and character-cell display library.

[Upstream](https://invisible-island.net/ncurses/) · 6.6.0 · MIT

```sh
ttrek install ncurses
ttrek run -package ncurses -script demo
```

Requires a C compiler and make.

Builds wide-character ncurses for Readline. All libraries and terminfo data are installed inside the ttrek prefix. The example describes the xterm terminal entry.
