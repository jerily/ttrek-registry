# pdf4tcl

Generate PDF documents in pure Tcl.

[Upstream](https://pdf4tcl.sourceforge.net/) · 0.9.4 · TCL

```sh
ttrek install pdf4tcl
ttrek run -package pdf4tcl -script demo
```

Pure Tcl; no compiler needed for this package. This recipe selects Tcl 8.6.

The example writes a PDF to a new temporary file and prints its path.
