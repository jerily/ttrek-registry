# readline

Line editing and history library for interactive programs.

[Upstream](https://tiswww.case.edu/php/chet/readline/rltop.html) · 8.3.6 · GPL-3.0-or-later

```sh
ttrek install readline
ttrek run -package readline -script demo
```

Requires a C compiler and make.

GNU Readline 8.3 with upstream patches 001–006. Links to the registry’s wide-character ncurses on Linux and macOS. The example compiles and runs a small history API program; a C compiler is required.
