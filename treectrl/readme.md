# treectrl

Flexible tree and multi-column list widget for Tk.

[Upstream](https://github.com/tcltk-depot/tktreectrl) · 2.5.2 · TCL

```sh
ttrek install treectrl
ttrek run -package treectrl -script demo
```

Requires a C compiler and make. Uses the registry’s X11 Tk on Linux and macOS. Install X11 development headers on Linux, or XQuartz on macOS; a display is needed to run the example. This recipe selects Tcl/Tk 8.6.

Pins upstream commit `51498c7837193d621069d1159577392f2bfc1fb2` (the sources declare version 2.5.2).
