# udp

UDP sockets for Tcl.

[Upstream](https://core.tcl-lang.org/tcludp/) · 1.0.14 · MIT

```sh
ttrek install udp
ttrek run -package udp -script demo
```

Requires a C compiler and make. This recipe selects Tcl 8.6.

The example sends and receives a datagram over the loopback interface; it does not contact an external server.
